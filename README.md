# Velo Ride Prototype

A single-file cycling dashboard prototype combining route guidance, rear-view camera preview, and ride metrics.

## Test on iPhone

Open the GitHub Pages link in Safari. Tap `START` to request camera access and the location button to request GPS access. Camera and location features require HTTPS and user permission.

External USB-C cameras may not be exposed consistently to mobile Safari; the iPhone rear camera is the primary browser prototype target.
